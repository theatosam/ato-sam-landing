How I build

Four rules every build has to pass.

  1. Eliminate before automating. If removing the task breaks nothing, stop there.
  2. Deterministic scripts do the work. The model decides and orchestrates.
  3. Every automation has an expiry condition. If it costs more time than it saves, it gets dismantled.
  4. The client owns everything. The files live in their account, not mine.
