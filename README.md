Ato Sam's personal hub. Push to master deploys on Vercel (project `ato-sam-landing`).

- `/` hub: Ato Sam's home page (navy). The latest three letters are written in by `tools/letters_sync.py` (run it after a letter publishes, then commit)
- `/labs` Autonomy Labs: websites, Google profiles, Review Engine, premium year
- `/letters` 307 to the Substack publication (the name Substack stays off the site)
- `/autonomous-mode` the Autonomous Mode offer page (moved from the autonomous-mode repo, 2026-10-27)
- `/privacy` site and gws-cli privacy policy
- `_archive/` the old landing page, not deployed (`.vercelignore`)
